Project 04 / Meeting Notes AI

Turn a recording into usable notes.

A practical n8n pipeline that turns meeting audio into structured notes: transcript, topics, decisions, action items, and a clear follow-up email.

Upload a recording or provide a Google Drive link. The workflow converts audio, transcribes it with Whisper, classifies the content, selects the right extraction path, and delivers Markdown or PDF to the recipient you choose.

01 / The pipeline

From raw audio to a useful handoff.

The workflow is deliberately staged. Each branch has a job, so the output is more useful than a raw transcript dumped into an inbox.

01 / INPUTUpload or link

File audio/video or a shared Google Drive link.

02 / NORMALIZEConvert audio

Normalize the incoming recording before transcription.

03 / TRANSCRIBEWhisper

Transcribe the recording, including longer files in chunks.

04 / CLASSIFYRoute content

Detect meeting, one-on-one, or non-meeting content.

05 / EXTRACTStructure notes

Pull out the fields that matter for that content type.

06 / DELIVEREmail output

Send the finished Markdown or PDF to the chosen address.

02 / Input & routing

One form, three useful paths.

Input A

Upload a recording

Use MP4, MKV, MOV, M4A, MP3, WAV, WEBM, or OGG. The form accepts files up to 150 MB and recordings up to 60 minutes.

Input B

Use Google Drive

Paste a shareable Drive file link when the recording is already stored elsewhere. The workflow extracts the file ID and downloads it before processing.

AI router

Classify first

The transcript is classified before extraction: regular meeting, one-on-one, or non-meeting content. Each route gets a purpose-built output structure.

03 / Deliverables

What comes back.

Meeting notes

Structured summary with meeting context, key topics, decisions, action items, owners, deadlines, and follow-up points extracted from the conversation.

One-on-one notes

A dedicated path for one-on-one conversations, keeping personal check-ins and development follow-ups separate from regular team-meeting structure.

Non-meeting content

A safer fallback for recordings that are not actually meetings, instead of forcing every piece of audio into a meeting template.

Markdown or PDF

Select the output format in the form. The result is delivered by email when an address is provided; the email field can accept multiple recipients separated by commas.

04 / Why it is useful

More than transcription.

Signal over noise

Decisions and tasks are first-class output

The workflow is designed around what a team needs after a meeting: what was decided, who owns the next move, and what needs to happen next.

Flexible handoff

Use the format your team already reads

Markdown stays easy to copy into existing tools; PDF gives you a stable attachment for records, clients, or formal follow-up.

Custom context

Tell the AI what to focus on

Add instructions such as “focus on technical action items”, “write in English”, or “ignore small talk” before processing.

Personal project

Built as an automation work sample

This demonstrates orchestration, media handling, AI classification, branching, structured extraction, and delivery in one practical workflow.

06 / Scope

Important constraints.

This is a portfolio demo and personal n8n deployment, not a production records-management system. Do not upload sensitive recordings without confirming that the setup is appropriate for them.

Limits

150 MB / 60 minutes

Those are the current form limits. Longer recordings may need to be split before submission, and transcription providers may apply their own rate limits.

Privacy

Use non-sensitive test material

Recordings pass through the configured transcription and AI services. Use sample or consented material for this public work sample.
